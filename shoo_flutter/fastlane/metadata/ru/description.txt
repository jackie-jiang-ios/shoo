Окружили дикие собаки? Во время кемпинга встретили ядовитую змею? Обезьяны тянут еду? Shoo предлагает научно обоснованное акустическое отпугивание, чтобы опасные животные держались подальше!

**Умные рекомендации звуков** Научно рекомендует самые эффективные отпугивающие звуки на основе сенсорных особенностей каждого животного. Рыканье тигра против диких собак, рык льва против кабанов, крик петуха против змей, крик орла против обезьян… каждый звук тщательно отобран.

**Богатая библиотека звуков** 6 категорий: Хищники, Рептилии, Приматы, Грызуны, Насекомые, Птицы. Встроены рыканье тигра, рык льва, вой волка, крик орла, лай собак, мяуканье, крик петуха, выстрелы, низкочастотные тоны, вибрации и многое другое — каждый звук с несколькими клипами.

**Микшер звуков** Миксуйте несколько звуков, накладывая разные частоты и тембры для усиленного отпугивания. Свободно регулируйте громкость каждого звука и создавайте свою защитную звуковую стену.

**Про-регулировка громкости** Общий и индивидуальный режимы громкости с оптимальной рекомендацией для каждого животного. Отображение предполагаемого уровня децибел и эффективной дальности в реальном времени.

**Гибкие режимы воспроизведения** Два режима: Непрерывный и Интервальный. Непрерывный режим выдаёт звук без перерыва для постоянного отпугивания; интервальный режим чередует воспроизведение для экономии батареи. Таймер автоостановки для энергосбережения.

**Связь с часами** Подключите умные часы для дистанционного управления воспроизведением с запястья — быстрое реагирование в экстренных ситуациях.

**Персонализированные иконки** Несколько стилей иконок для каждого животного — свободно переключайтесь между иллюстрацией и реализмом для персонализации интерфейса.

**Сценарии использования**

- Походы и кемпинг — отпугивание диких собак, волков, змей, кабанов
- Защита фермы — отпугивание диких кроликов, ворон
- Защита дома — отпугивание мышей, лис, ос
- Тропические путешествия — отпугивание обезьян, ядовитых пауков

**Внимание:** Данное приложение основано на принципе акустического отпугивания. Эффективность зависит от вида животного, условий среды и громкости устройства. В опасных ситуациях сначала обеспечьте личную безопасность и немедленно обратитесь в специализированные службы.
